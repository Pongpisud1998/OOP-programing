## การเปรียบเทียบให้ผลเป็น True หรือ False

เมื่อเราเปรียบเทียบค่าสองค่า Python จะตอบกลับมาเป็นค่าชนิดใหม่ที่เรียกว่า `bool` ซึ่งมีได้แค่สองค่า คือ `True` (จริง) และ `False` (ไม่จริง)

```python
area = 1554
print(area > 1000)
print(area > 2000)
```

บรรทัดแรกได้ `True` บรรทัดที่สองได้ `False`

`True` และ `False` ขึ้นต้นด้วยตัวพิมพ์ใหญ่และไม่มีเครื่องหมายคำพูด ถ้าใส่เครื่องหมายคำพูดจะกลายเป็นข้อความธรรมดา

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผล |
|---|---|---|---|
| `==` | เท่ากัน | `3 == 3` | `True` |
| `!=` | ไม่เท่ากัน | `3 != 3` | `False` |
| `>` | มากกว่า | `400 > 400` | `False` |
| `>=` | มากกว่าหรือเท่ากับ | `400 >= 400` | `True` |
| `<` | น้อยกว่า | `399 < 400` | `True` |
| `<=` | น้อยกว่าหรือเท่ากับ | `401 <= 400` | `False` |

ผลของการเปรียบเทียบเก็บไว้ในตัวแปรได้เหมือนค่าอื่น

```python
is_big = area > 1000
print(is_big)
```

### `=` กับ `==` ไม่เหมือนกัน

จุดนี้ทำให้คนเริ่มเขียนโปรแกรมพลาดบ่อยที่สุดในบทนี้

- `=` ตัวเดียว คือคำสั่งผูกชื่อกับค่า เช่น `area = 1554`
- `==` สองตัว คือคำถามว่าสองฝั่งเท่ากันไหม เช่น `area == 1554`

ข้อความก็เปรียบเทียบได้ และต้องตรงกันทุกตัวอักษร `"โฉนด" == "โฉนด"` ได้ `True` แต่ `"นส.3" == "น.ส.3"` ได้ `False` เพราะมีจุดต่างกันหนึ่งตัว

## if: ทำเมื่อเงื่อนไขเป็นจริง

```python
area = 1554

if area > 1000:
    print("แปลงนี้เกิน 1000 ตารางวา")

print("จบโปรแกรม")
```

รูปแบบมี 3 ส่วนที่ขาดไม่ได้

1. คำว่า `if` ตามด้วยเงื่อนไข
2. เครื่องหมาย `:` ท้ายบรรทัด
3. บรรทัดถัดไปย่อหน้าเข้าไป 4 ช่อง (กดปุ่ม Tab หนึ่งครั้งใน VS Code)

บรรทัดที่ย่อหน้าอยู่ใต้ `if` จะทำงานเฉพาะเมื่อเงื่อนไขเป็น `True` ส่วนบรรทัดที่กลับมาชิดซ้ายถือว่าพ้นจาก `if` แล้ว และทำงานเสมอ

ลองเปลี่ยน `area` เป็น `500` แล้วรันอีกรอบ จะเห็นแต่ `จบโปรแกรม`

การย่อหน้าใน Python มีความหมาย ไม่ใช่แค่ความสวยงาม ถ้าย่อหน้าผิดจะได้ `IndentationError`

## else: ทำเมื่อเงื่อนไขไม่จริง

```python
if area > 1000:
    note = "เกิน 1000 ตารางวา"
else:
    note = "ไม่เกิน 1000 ตารางวา"

print(note)
```

Python จะทำแค่ทางเดียวจากสองทาง ไม่มีกรณีที่ทำทั้งคู่หรือไม่ทำเลย

`else` ไม่มีเงื่อนไขของตัวเอง แต่ต้องมี `:` และต้องอยู่ชิดซ้ายระดับเดียวกับ `if`

ในตัวอย่างนี้เราสร้างตัวแปร `note` ไว้ข้างใน `if` และ `else` ไม่ว่าจะเข้าทางไหน `note` ก็ถูกสร้างเสมอ จึงนำไปใช้ต่อข้างล่างได้

## elif: มีมากกว่าสองทาง

`elif` ย่อมาจาก else if ใช้เมื่อมีทางเลือกมากกว่าสองทาง

```python
score = 72

if score >= 80:
    grade = "ดีมาก"
elif score >= 50:
    grade = "ผ่าน"
else:
    grade = "ไม่ผ่าน"

print(grade)
```

Python ตรวจเงื่อนไขจากบนลงล่าง **เจอข้อแรกที่เป็นจริงแล้วทำข้อนั้น จากนั้นข้ามที่เหลือทั้งหมด**

เพราะแบบนี้ บรรทัด `elif score >= 50` จึงไม่ต้องเขียนว่า "และน้อยกว่า 80" ถ้า Python มาถึงบรรทัดนี้ได้ แปลว่าเงื่อนไขแรกไม่จริง คะแนนจึงน้อยกว่า 80 แน่นอนอยู่แล้ว

ลองสลับลำดับ โดยเอาเงื่อนไข `score >= 50` ขึ้นไปไว้ก่อน `score >= 80` แล้วตั้ง `score = 95` ดูว่าได้อะไร และคิดว่าทำไมถึงเป็นแบบนั้น

## and, or: รวมหลายเงื่อนไข

| คำ | เป็นจริงเมื่อ | ตัวอย่าง | ผล |
|---|---|---|---|
| `and` | จริงทั้งสองฝั่ง | `5 > 3 and 5 > 10` | `False` |
| `or` | จริงอย่างน้อยหนึ่งฝั่ง | `5 > 3 or 5 > 10` | `True` |

```python
age = 20
has_ticket = True

can_enter = age >= 18 and has_ticket
print(can_enter)
```

ข้อควรระวัง: แต่ละฝั่งของ `and` และ `or` ต้องเป็นการเปรียบเทียบที่สมบูรณ์ในตัวเอง

```python
color = "แดง"

print(color == "แดง" or color == "ส้ม")
print(color == "แดง" or "ส้ม")
```

บรรทัดแรกถูกต้อง บรรทัดที่สองดูเหมือนภาษาพูดแต่ทำงานผิด ลองเปลี่ยน `color` เป็น `"เขียว"` แล้วดูว่าบรรทัดที่สองให้ผลอะไร มันจะไม่เป็น `False` อย่างที่ตั้งใจ

## สรุปสิ่งที่ได้ในบทนี้

- การเปรียบเทียบให้ผลเป็น `True` หรือ `False`
- `=` คือผูกชื่อกับค่า `==` คือถามว่าเท่ากันไหม

- `and` ต้องจริงทั้งคู่ `or` จริงฝั่งเดียวก็พอ
