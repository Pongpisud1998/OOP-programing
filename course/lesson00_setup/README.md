# บทที่ 0: เตรียมเครื่องและโปรแกรมแรก

จบบทนี้เราจะมีเครื่องที่พร้อมเขียนโปรแกรม รันโปรแกรม Python ที่เขียนเองได้ อ่านข้อความแจ้งข้อผิดพลาดเป็น และส่งงานให้พี่เลี้ยงตรวจได้

บทนี้ยาวที่สุดในคอร์สเพราะต้องติดตั้งหลายอย่าง ทำไปทีละขั้น ถ้าขั้นไหนผลลัพธ์ไม่ตรงกับที่เขียนไว้ ให้หยุดแล้วถามพี่เลี้ยง อย่าข้ามไปขั้นถัดไป

## ส่วนที่ 1: ติดตั้งเครื่องมือ

### ขั้นที่ 1: บัญชี GitHub

GitHub คือเว็บไซต์ที่เก็บโค้ดของคอร์สนี้ และเป็นที่ที่เราจะส่งงาน

1. สมัครบัญชีที่ https://github.com (ถ้ามีแล้วข้ามได้)
2. แจ้งชื่อผู้ใช้ (username) ให้พี่เลี้ยง
3. รออีเมลเชิญจาก GitHub แล้วกดรับคำเชิญ

### ขั้นที่ 2: Python

Python คือโปรแกรมที่อ่านโค้ดที่เราเขียนแล้วทำตาม

| | macOS | Windows |
|---|---|---|
| ดาวน์โหลด | https://www.python.org/downloads/ | https://www.python.org/downloads/ |
| ตอนติดตั้ง | กดถัดไปจนจบ | **ติ๊กช่อง "Add python.exe to PATH" ในหน้าแรกก่อนกด Install** |

### ขั้นที่ 3: Git

Git คือเครื่องมือบันทึกประวัติการแก้ไขโค้ดและส่งโค้ดขึ้น GitHub

| | macOS | Windows |
|---|---|---|
| วิธีติดตั้ง | เปิดแอป Terminal พิมพ์ `git --version` แล้วกด Enter ถ้ายังไม่มี เครื่องจะถามว่าจะติดตั้งไหม ให้กด Install | ดาวน์โหลดจาก https://git-scm.com/download/win แล้วกดถัดไปจนจบ |

### ขั้นที่ 4: VS Code

VS Code คือโปรแกรมที่เราใช้พิมพ์โค้ด

1. ดาวน์โหลดและติดตั้งจาก https://code.visualstudio.com
2. เปิด VS Code กดไอคอนรูปสี่เหลี่ยมสี่ช่องที่แถบซ้าย (Extensions) ค้นคำว่า `Python` แล้วกด Install ตัวที่ผู้พัฒนาคือ Microsoft

### ขั้นที่ 5: นำโค้ดของคอร์สลงเครื่อง

การคัดลอกโค้ดจาก GitHub ลงเครื่องเรียกว่า clone

1. ใน VS Code กด `Cmd+Shift+P` (macOS) หรือ `Ctrl+Shift+P` (Windows) จะมีช่องพิมพ์คำสั่งขึ้นมาด้านบน
2. พิมพ์ `Git: Clone` แล้วกด Enter
3. วางที่อยู่นี้แล้วกด Enter: `https://github.com/Pongpisud1998/OOP-programing.git`
4. ถ้า VS Code ขอให้เข้าสู่ระบบ GitHub ให้ทำตามจนเสร็จ
5. เลือกโฟลเดอร์ที่จะเก็บโค้ด เช่น Documents
6. เมื่อถามว่าจะเปิดโฟลเดอร์ที่ clone มาไหม กด Open

### ขั้นที่ 6: เปิด terminal และตรวจว่าทุกอย่างพร้อม

terminal คือหน้าต่างที่เราพิมพ์คำสั่งให้เครื่องทำงาน ใน VS Code เปิดได้จากเมนู Terminal > New Terminal จะมีแผงขึ้นมาด้านล่าง

พิมพ์คำสั่งทีละบรรทัดแล้วกด Enter

| สิ่งที่ตรวจ | macOS | Windows | ผลที่ควรเห็น |
|---|---|---|---|
| Python | `python3 --version` | `python --version` | `Python 3.10` ขึ้นไป |
| Git | `git --version` | `git --version` | `git version ...` |

> **ข้อตกลงเรื่องคำสั่ง:** บน macOS คำสั่งเรียก Python คือ `python3` ส่วนบน Windows คือ `python` เอกสารของคอร์สนี้จะเขียนว่า `python` เสมอ ถ้าใช้ macOS ให้พิมพ์ `python3` แทนทุกครั้ง

จากนั้นเข้าไปในโฟลเดอร์ของคอร์ส

```
cd course
```

`cd` ย่อมาจาก change directory แปลว่าย้ายไปทำงานในโฟลเดอร์นั้น คำสั่งทั้งหมดในคอร์สนี้ต้องรันจากโฟลเดอร์ `course` ถ้าปิด terminal แล้วเปิดใหม่ ต้องพิมพ์ `cd course` อีกครั้ง

### ขั้นที่ 7: แนะนำตัวกับ Git และสร้างพื้นที่งานของตัวเอง

บอก Git ว่าเราเป็นใคร ทำครั้งเดียวต่อเครื่อง (ใส่ชื่อและอีเมลของตัวเองแทนตัวอย่าง)

```
git config --global user.name "ชื่อของเรา"
git config --global user.email "อีเมลที่ใช้สมัคร GitHub"
```

สร้าง branch ของตัวเอง branch คือพื้นที่งานแยกที่เราแก้โค้ดได้โดยไม่กระทบของคนอื่น ใส่ชื่อเล่นเป็นภาษาอังกฤษแทน `yourname`

```
git switch -c intern/yourname
```

## ส่วนที่ 2: โปรแกรมแรก

### รันโปรแกรม

ในแถบซ้ายของ VS Code เปิดไฟล์ `course/lesson00_setup/exercise.py` แล้วพิมพ์คำสั่งนี้ใน terminal

```
python lesson00_setup/exercise.py
```

จะเห็นข้อความ `บรรทัดนี้ต้องไม่แสดง` ขึ้นมา แปลว่า Python อ่านไฟล์แล้วทำตามคำสั่งในไฟล์ได้แล้ว

### คำสั่ง print

`print` สั่งให้ Python แสดงสิ่งที่อยู่ในวงเล็บออกทางหน้าจอ

```python
print("สวัสดี")
```

สิ่งที่ต้องรู้เกี่ยวกับบรรทัดนี้

- ข้อความต้องอยู่ในเครื่องหมายคำพูด `"..."` ข้อความแบบนี้เรียกว่า string
- ตัวเลขไม่ต้องมีเครื่องหมายคำพูด เช่น `print(40)`
- แสดงหลายอย่างในครั้งเดียวได้โดยคั่นด้วยเครื่องหมาย `,` เช่น `print("อายุ", 20)` จะได้ `อายุ 20` โดย Python เติมช่องว่างคั่นให้เอง
- Python ทำงานจากบรรทัดบนลงล่างทีละบรรทัด

### comment

บรรทัดที่ขึ้นต้นด้วย `#` เรียกว่า comment Python จะข้ามบรรทัดนั้นไป ใช้เขียนโน้ตให้คนอ่าน หรือใช้ปิดการทำงานของโค้ดบรรทัดหนึ่งไว้ชั่วคราว

```python
# บรรทัดนี้ Python ไม่อ่าน
print("บรรทัดนี้ทำงาน")
# print("บรรทัดนี้ถูกปิดไว้")
```

### บันทึกไฟล์ก่อนรันทุกครั้ง

Python อ่านไฟล์ที่บันทึกแล้วเท่านั้น ถ้าแท็บชื่อไฟล์ด้านบนมีจุดกลม ๆ แปลว่ายังไม่ได้บันทึก กด `Cmd+S` (macOS) หรือ `Ctrl+S` (Windows) ก่อนรัน นี่เป็นสาเหตุอันดับหนึ่งของอาการ "แก้แล้วแต่ผลไม่เปลี่ยน"

### อ่านข้อความแจ้งข้อผิดพลาด

เมื่อโค้ดผิด Python จะหยุดและบอกว่าผิดตรงไหน ข้อความนี้เรียกว่า error มันไม่ใช่การดุ มันคือคำบอกทาง และโปรแกรมเมอร์ทุกคนเจอทุกวัน

ตัวอย่าง ถ้าลืมปิดเครื่องหมายคำพูด

```
  File "lesson00_setup/exercise.py", line 12
    print("สวัสดี)
          ^
SyntaxError: unterminated string literal (detected at line 12)
```

อ่านจากล่างขึ้นบน 3 จุด

1. **บรรทัดล่างสุด** บอกชนิดและสาเหตุ `SyntaxError` แปลว่าเขียนผิดรูปแบบของภาษา ส่วน `unterminated string` แปลว่าข้อความไม่มีตัวปิด
2. **`line 12`** บอกว่าผิดที่บรรทัดที่ 12 (เลขบรรทัดอยู่ทางซ้ายของโค้ดใน VS Code)
3. **เครื่องหมาย `^`** ชี้ตำแหน่งในบรรทัดที่ Python เริ่มสับสน

ถ้าดูบรรทัดที่แจ้งแล้วไม่เห็นว่าผิดตรงไหน ให้ดูบรรทัดก่อนหน้าด้วย

## ส่วนที่ 4: ส่งงาน

เมื่อข้อบังคับผ่านครบ ส่งงานด้วย 3 คำสั่งนี้

```
git add .
git commit -m "lesson 0 done"
git push -u origin intern/yourname
```

| คำสั่ง | ความหมาย |
|---|---|
| `git add .` | เลือกไฟล์ทั้งหมดที่แก้ไว้เพื่อเตรียมบันทึก |
| `git commit -m "..."` | บันทึกเป็นจุดหนึ่งในประวัติ พร้อมข้อความอธิบายสั้น ๆ |
| `git push` | ส่งประวัติขึ้น GitHub ให้พี่เลี้ยงเห็น |

ครั้งต่อไปพิมพ์แค่ `git push` ก็พอ ไม่ต้องมี `-u origin intern/yourname`

## สรุปสิ่งที่ได้ในบทนี้

- รันไฟล์ Python ด้วย `python ชื่อไฟล์`
- `print(...)` แสดงผลออกหน้าจอ ข้อความอยู่ในเครื่องหมายคำพูด ตัวเลขไม่ต้อง
- `#` คือ comment
- อ่าน error จากล่างขึ้นบน ดูชนิด เลขบรรทัด และตำแหน่งที่ชี้
- ส่งงานด้วย `git add`, `git commit`, `git push`
