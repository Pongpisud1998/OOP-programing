# คอร์สพื้นฐานการเขียนโปรแกรมด้วย Python

คอร์สนี้สำหรับคนที่ไม่เคยเขียนโปรแกรมมาก่อน เรียนด้วยตัวเองทีละบท ลงมือทำแบบฝึกหัด แล้วให้พี่เลี้ยงตรวจ

โจทย์ทั้งคอร์สใช้ข้อมูลแปลงที่ดินจริง 40 แปลง เมื่อจบคอร์ส เราจะเขียนโค้ดที่คำนวณข้อมูลของแปลงที่ดิน แล้วเห็นผลของโค้ดตัวเองบนแผนที่

## แต่ละบทมีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `README.md` | เนื้อหาของบท อ่านก่อน |
| `exercise.py` | แบบฝึกหัด เราเขียนโค้ดลงในไฟล์นี้ |
| `hints.md` | คำใบ้ 3 ระดับสำหรับแต่ละข้อ |
| `checks.py` | เกณฑ์ที่ตัวตรวจใช้ ไม่ต้องแก้ |

## วิธีเรียนแต่ละบท

1. อ่าน `README.md` ของบท และพิมพ์ตัวอย่างโค้ดทุกอันด้วยมือตัวเองลงในไฟล์ `try.py`
2. เปิด `exercise.py` ทำทีละข้อ บันทึก รัน แล้วดูผล
3. ตรวจด้วย `python check.py <เลขบท>` จากโฟลเดอร์ `course`
4. เมื่อข้อบังคับผ่านครบ ให้ commit และ push
5. อธิบายโค้ดของตัวเองให้พี่เลี้ยงฟังตอนตรวจงาน

> บน macOS ให้พิมพ์ `python3` แทน `python` ทุกครั้ง

## เกณฑ์ผ่านบท

ผ่านบทเมื่อครบสองอย่าง

1. ตัวตรวจแจ้งว่าข้อบังคับผ่านครบทุกข้อ
2. อธิบายได้ว่าโค้ดแต่ละบรรทัดของตัวเองทำอะไร และทำไมถึงเขียนแบบนั้น

ข้อท้าทายไม่บังคับ ทำเมื่อมีเวลาเหลือ ระหว่างรอพี่เลี้ยงตรวจ อ่านบทถัดไปล่วงหน้าได้

## เมื่อติด

ทำตามลำดับนี้ และอย่าข้ามขั้น

1. อ่านข้อความจากตัวตรวจหรือ error ให้จบทั้งข้อความ ส่วนใหญ่คำตอบอยู่ในนั้น
2. กลับไปอ่านหัวข้อที่เกี่ยวข้องใน `README.md` ของบท
3. ทดลองในไฟล์ `try.py` ด้วยตัวอย่างที่เล็กกว่าโจทย์
4. เปิด `hints.md` ทีละระดับ
5. ถามพี่เลี้ยง โดยบอกว่าลองอะไรไปแล้วและได้ผลอย่างไร

การติดเป็นเรื่องปกติของการเขียนโปรแกรม เวลาที่ใช้แก้ปัญหาด้วยตัวเองคือช่วงที่ได้เรียนรู้มากที่สุด

## กติกาการใช้ AI

ใช้ได้

- ถามให้อธิบายแนวคิดที่ยังไม่เข้าใจ เช่น "ตัวแปรคืออะไร ยกตัวอย่างให้หน่อย"
- ถามให้อธิบายความหมายของ error

ห้ามใช้

- ให้ AI เขียนคำตอบของแบบฝึกหัดบท 0 ถึง 8 หรือวางโจทย์ให้ AI ทำ

เหตุผลคือทักษะการเขียนโปรแกรมเกิดจากการคิดและพิมพ์เอง โค้ดที่ AI เขียนให้จะผ่านตัวตรวจได้ แต่เราจะอธิบายไม่ได้ตอนพี่เลี้ยงถาม และจะทำบทถัดไปไม่ได้
