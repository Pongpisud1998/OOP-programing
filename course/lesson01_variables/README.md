# บทที่ 1: ค่าและตัวแปร

จบบทนี้เราจะให้ Python จำค่าไว้ในชื่อที่เราตั้งเอง นำค่าเหล่านั้นมาคำนวณ และประกอบเป็นข้อความได้ โจทย์ของบทนี้คือการแปลงเนื้อที่ดินจาก ไร่ งาน ตารางวา ให้เป็นตารางวาอย่างเดียว

## วิธีเรียนบทนี้

สร้างไฟล์ใหม่ชื่อ `try.py` ในโฟลเดอร์ `lesson01_variables` ไว้เป็นกระดาษทด ทุกครั้งที่บทเรียนมีตัวอย่างโค้ด ให้พิมพ์ลงใน `try.py` ด้วยมือตัวเอง (อย่าคัดลอกแล้ววาง) แล้วรันดูผล

```
python lesson01_variables/try.py
```

การพิมพ์เองทำให้มือและตาคุ้นกับรูปแบบของภาษา ซึ่งการอ่านอย่างเดียวให้ไม่ได้

## ค่าและชนิดของค่า

ทุกอย่างที่ Python ทำงานด้วยเรียกว่าค่า (value) แต่ละค่ามีชนิด (type) บทนี้ใช้ 3 ชนิด

| ชนิด | ชื่อใน Python | ตัวอย่าง | สังเกตจาก |
|---|---|---|---|
| จำนวนเต็ม | `int` | `3`, `40`, `11304` | ตัวเลขที่ไม่มีจุด |
| จำนวนทศนิยม | `float` | `54.7`, `3.0` | ตัวเลขที่มีจุด |
| ข้อความ | `str` | `"โฉนด"`, `"54"` | อยู่ในเครื่องหมายคำพูด |

ระวัง `54` กับ `"54"` เป็นคนละชนิด ตัวแรกเป็นตัวเลขที่นำไปคำนวณได้ ตัวหลังเป็นข้อความที่บังเอิญมีหน้าตาเป็นตัวเลข

## ตัวแปร

ตัวแปร (variable) คือชื่อที่เราตั้งให้กับค่า เพื่อเรียกใช้ค่านั้นทีหลัง

```python
rai = 3
print(rai)
```

บรรทัดแรกอ่านว่า "ให้ชื่อ `rai` หมายถึงค่า 3" บรรทัดที่สองแสดง `3`

เครื่องหมาย `=` ใน Python ไม่ได้แปลว่า "เท่ากับ" แบบในวิชาคณิตศาสตร์ มันเป็นคำสั่งให้ทำงาน คือให้คำนวณฝั่งขวาจนได้ค่าก่อน แล้วผูกชื่อทางฝั่งซ้ายเข้ากับค่านั้น

ลองดูความต่างของสองบรรทัดนี้

```python
print(rai)
print("rai")
```

บรรทัดแรกแสดงค่าที่ชื่อ `rai` หมายถึง คือ `3` บรรทัดที่สองแสดงข้อความ `rai` เพราะมีเครื่องหมายคำพูด

### กติกาการตั้งชื่อ

- ใช้ตัวอักษรภาษาอังกฤษพิมพ์เล็ก ตัวเลข และขีดล่าง `_`
- ห้ามมีช่องว่าง ถ้ามีหลายคำให้คั่นด้วย `_` เช่น `total_sq_wa`
- ห้ามขึ้นต้นด้วยตัวเลข
- ตัวพิมพ์เล็กกับตัวพิมพ์ใหญ่ถือเป็นคนละชื่อ `rai` กับ `Rai` ไม่ใช่ตัวเดียวกัน
- ตั้งชื่อให้บอกว่าค่านั้นคืออะไร `total_sq_wa` อ่านรู้เรื่องกว่า `x`

## การคำนวณ

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผล |
|---|---|---|---|
| `+` | บวก | `300 + 54` | `354` |
| `-` | ลบ | `400 - 54` | `346` |
| `*` | คูณ | `3 * 400` | `1200` |
| `/` | หาร | `1200 / 400` | `3.0` |

การหารด้วย `/` ให้ผลเป็นทศนิยมเสมอ แม้จะหารลงตัว

Python คูณและหารก่อนบวกและลบเหมือนคณิตศาสตร์ ถ้าอยากให้ส่วนไหนทำก่อนให้ใส่วงเล็บ

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

บรรทัดแรกได้ `14` บรรทัดที่สองได้ `20`

### คำนวณจากตัวแปร

ใช้ชื่อตัวแปรแทนตัวเลขในการคำนวณได้ และเก็บผลไว้ในตัวแปรใหม่ได้

```python
width = 20
length = 30
area = width * length
print(area)
```

ข้อดีคือถ้าเปลี่ยนค่าใน `width` สูตรข้างล่างไม่ต้องแก้เลย นี่คือเหตุผลที่แบบฝึกหัดบทนี้ให้คำนวณจากตัวแปร ไม่ให้พิมพ์ตัวเลขคำตอบลงไปเอง

### ตัวแปรไม่อัปเดตตามกันเอง

พิมพ์ตัวอย่างนี้ลง `try.py` แล้วทายผลก่อนรัน

```python
a = 5
b = a * 2
a = 100
print(b)
```

ผลคือ `10` ไม่ใช่ `200` เพราะตอน Python ทำบรรทัดที่สอง มันคำนวณ `5 * 2` ได้ `10` แล้วผูกชื่อ `b` กับค่า `10` ไปแล้ว `b` ไม่ได้จำสูตร จำแค่ผลลัพธ์ การเปลี่ยน `a` ทีหลังจึงไม่มีผลกับ `b`

## ประกอบข้อความด้วย f-string

เมื่อต้องการข้อความที่มีค่าของตัวแปรแทรกอยู่ ให้ใส่ตัว `f` ไว้หน้าเครื่องหมายคำพูด แล้วใส่ชื่อตัวแปรในวงเล็บปีกกา `{}`

```python
name = "ต้นกล้า"
age = 20
text = f"{name} อายุ {age} ปี"
print(text)
```

ได้ `ต้นกล้า อายุ 20 ปี` Python แทนที่ `{name}` และ `{age}` ด้วยค่าของตัวแปร ส่วนอื่นของข้อความอยู่ตามเดิมทุกตัวอักษร รวมถึงช่องว่าง

ถ้าลืมตัว `f` จะได้ข้อความ `{name} อายุ {age} ปี` ออกมาตรง ๆ

## ทดลองทำให้พัง

error สองชนิดนี้จะเจอบ่อยที่สุดในบทนี้ ลองทำให้เกิดขึ้นเองใน `try.py` เพื่อให้จำหน้าตาได้

**พิมพ์ชื่อตัวแปรผิด**

```python
rai = 3
print(rei)
```

ได้ `NameError: name 'rei' is not defined` แปลว่า Python ไม่รู้จักชื่อ `rei` เพราะไม่เคยมีบรรทัดไหนสร้างมัน

**เอาข้อความไปบวกกับตัวเลข**

```python
print("เลขที่ " + 11304)
```

ได้ `TypeError: can only concatenate str (not "int") to str` แปลว่าเครื่องหมาย `+` ต่อข้อความกับข้อความได้ แต่ต่อข้อความกับตัวเลขไม่ได้ วิธีแก้ที่ง่ายที่สุดคือใช้ f-string

## หารปัดเศษทิ้งและเศษจากการหาร

ส่วนนี้ใช้ในข้อท้าทาย ข้ามได้ถ้าไม่ทำ

| เครื่องหมาย | ความหมาย | ตัวอย่าง | ผล |
|---|---|---|---|
| `//` | หารแล้วเอาแต่จำนวนเต็ม | `17 // 5` | `3` |
| `%` | เศษที่เหลือจากการหาร | `17 % 5` | `2` |

ตัวอย่างการใช้: 135 นาทีเท่ากับกี่ชั่วโมงกี่นาที `135 // 60` ได้ `2` ชั่วโมง และ `135 % 60` ได้เศษ `15` นาที

## สรุปสิ่งที่ได้ในบทนี้

- ค่ามีชนิด: `int`, `float`, `str`
- `ชื่อ = ค่า` สร้างตัวแปร โดยคำนวณฝั่งขวาก่อนแล้วผูกกับชื่อทางซ้าย
- ตัวแปรจำผลลัพธ์ ไม่ได้จำสูตร
- `+ - * /` คำนวณได้ทั้งกับตัวเลขและตัวแปร
- `f"...{ชื่อตัวแปร}..."` แทรกค่าของตัวแปรลงในข้อความ
- `NameError` มักมาจากสะกดชื่อผิด `TypeError` มักมาจากใช้ค่าผิดชนิด
