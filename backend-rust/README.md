# เอกสารเสริม: ติดตั้ง Rust และรัน Backend Rust

เอกสารนี้ไม่บังคับ และไม่ใช่บทเรียนของคอร์ส แผนที่ใช้งานได้ครบโดยไม่ต้องมี Rust เพราะ backend หลักคือ Python

ทำตามเอกสารนี้เมื่ออยากเห็นข้อมูลชุดที่สองบนแผนที่ คือข้อมูลภาษีที่ดินของขอนแก่น (แปลงที่ดินกว่า 3,600 แปลง) ซึ่งให้บริการโดย backend ที่เขียนด้วยภาษา Rust

เอกสารนี้สอนติดตั้งและรันเท่านั้น ไม่ได้สอนเขียนภาษา Rust

## Rust กับ cargo คืออะไร

- **Rust** คือภาษาเขียนโปรแกรมอีกภาษาหนึ่ง ต่างจาก Python ตรงที่ต้องแปลงโค้ดทั้งหมดเป็นโปรแกรมก่อนจึงจะรันได้ ขั้นตอนแปลงนี้เรียกว่า build
- **cargo** คือเครื่องมือของ Rust ที่ใช้ build รัน และทดสอบโค้ด เราจะพิมพ์คำสั่ง `cargo` เป็นหลัก
- **rustup** คือตัวติดตั้งที่นำ Rust และ cargo ลงเครื่องให้

## ขั้นที่ 1: ติดตั้ง

### macOS

1. เปิด terminal แล้ววางคำสั่งนี้ กด Enter

   ```
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. เมื่อตัวติดตั้งถามว่าจะติดตั้งแบบไหน กด Enter เพื่อเลือกค่าเริ่มต้น แล้วรอจนเสร็จ

### Windows

1. เปิด https://www.rust-lang.org/tools/install แล้วดาวน์โหลด `rustup-init.exe` (เครื่องทั่วไปเลือกแบบ 64-bit)
2. เปิดไฟล์ที่ดาวน์โหลดมา จะมีหน้าต่างสีดำขึ้นมา
3. Rust บน Windows ต้องใช้เครื่องมือของ Microsoft ชื่อ Visual Studio C++ Build Tools ถ้าเครื่องยังไม่มี ตัวติดตั้งจะแจ้งและเสนอติดตั้งให้อัตโนมัติ ให้ตอบรับ แล้วทำตามหน้าต่าง Visual Studio Installer ที่เปิดขึ้นมาจนเสร็จ ไฟล์ส่วนนี้มีขนาดใหญ่ ใช้เวลาดาวน์โหลดนาน
4. กลับมาที่หน้าต่างสีดำ เมื่อถามว่าจะติดตั้งแบบไหน กด Enter เพื่อเลือกค่าเริ่มต้น แล้วรอจนเสร็จ

ถ้าต้องเลือกส่วนประกอบใน Visual Studio Installer เอง ให้ติ๊กชุดที่ชื่อ **Desktop development with C++**

## ขั้นที่ 2: ตรวจว่าติดตั้งสำเร็จ

terminal ที่เปิดไว้ก่อนติดตั้งจะยังไม่รู้จักคำสั่งใหม่ ให้ **ปิด VS Code ทั้งโปรแกรมแล้วเปิดใหม่** จากนั้นเปิด terminal แล้วพิมพ์

```
cargo --version
```

ควรเห็นข้อความขึ้นต้นด้วย `cargo` ตามด้วยเลขรุ่น เช่น `cargo 1.90.0` ถ้าเห็นแบบนี้แปลว่าพร้อมแล้ว

## ขั้นที่ 3: รันแผนที่พร้อม Backend Rust

รันจากโฟลเดอร์หลักของโปรเจกต์ (โฟลเดอร์ที่มีไฟล์ `start.py`) ด้วยคำสั่งเดิม

```
python start.py
```

เมื่อเครื่องมี cargo แล้ว คำสั่งนี้จะ build และรัน Backend Rust ให้เองโดยไม่ต้องตั้งค่าเพิ่ม

**ครั้งแรกจะนานหลายนาที** เพราะ cargo ต้องดาวน์โหลดไลบรารีและ build ทั้งหมด จะเห็นบรรทัด `Compiling ...` ไล่ขึ้นมาจำนวนมาก ซึ่งเป็นเรื่องปกติ ต้องต่ออินเทอร์เน็ตไว้ ครั้งถัดไปจะใช้เวลาไม่กี่วินาที

รอจนเห็นกรอบ `พร้อมใช้งานแล้ว` ซึ่งจะมีบรรทัด `Backend Rust` เพิ่มขึ้นมา จากนั้น

1. เปิด http://localhost:5173 ในเบราว์เซอร์
2. กดปุ่ม **Rust (LTAX ขอนแก่น)** ที่แถบด้านบน
3. แผนที่จะย้ายไปที่ขอนแก่น และแสดงโซนภาษี บล็อกภาษี แปลงที่ดิน และอาคาร
4. กดปุ่ม **FastAPI (DPT สตูล)** เพื่อกลับไปที่ข้อมูลของ backend Python

ตรวจ backend โดยตรงได้ที่ http://localhost:8080/api/health ควรเห็นข้อความที่มี `"backend":"rust-axum"`

## คำสั่งอื่นที่ใช้ได้

| ต้องการ | คำสั่ง | รันจากโฟลเดอร์ |
|---|---|---|
| รัน Backend Rust ตัวเดียว | `python start.py rust` | โฟลเดอร์หลัก |
| รัน test ของทั้งสอง backend | `python start.py test` | โฟลเดอร์หลัก |
| รันด้วย cargo โดยตรง | `cargo run` | `backend-rust` |
| รัน test ด้วย cargo โดยตรง | `cargo test` | `backend-rust` |
| อัปเดต Rust เป็นรุ่นใหม่ | `rustup update` | ที่ไหนก็ได้ |
| ถอนการติดตั้ง Rust | `rustup self uninstall` | ที่ไหนก็ได้ |

`cargo run` ต้องรันจากโฟลเดอร์ `backend-rust` เท่านั้น เพราะโค้ดหาไฟล์ข้อมูลจากตำแหน่งของโฟลเดอร์นี้

test จะเขียนและลบข้อมูลใน `data/ltax/user_drawings.geojson` จริง

## อาการที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| พิมพ์ `cargo --version` แล้วขึ้นว่าไม่รู้จักคำสั่ง | terminal ยังเป็นตัวเก่า ปิด VS Code ทั้งโปรแกรมแล้วเปิดใหม่ ถ้ายังไม่ได้ ให้ออกจากระบบของเครื่องแล้วเข้าใหม่ |
| `python start.py` ยังขึ้นว่า `ไม่พบ Rust ในเครื่อง` | สาเหตุเดียวกับข้อบน |
| Windows: build แล้วขึ้น `linker 'link.exe' not found` | ยังไม่มี Visual Studio C++ Build Tools เปิดโปรแกรม Visual Studio Installer แล้วติดตั้งชุด **Desktop development with C++** |
| build ครั้งแรกค้างนาน | ปกติ ครั้งแรกใช้เวลาหลายนาที ตราบใดที่ยังมีบรรทัด `Compiling ...` ขึ้นใหม่อยู่ ให้รอต่อ |
| build ขึ้น error เรื่องดาวน์โหลดไม่ได้ | ครั้งแรกต้องต่ออินเทอร์เน็ต ตรวจการเชื่อมต่อแล้วรันใหม่ |
| ขึ้นว่าพอร์ต 8080 ถูกใช้อยู่ | มี `start.py` หรือ `cargo run` รันค้างอยู่ในอีกหน้าต่างหนึ่ง ไปกด Ctrl+C ที่หน้าต่างนั้น |

เมื่อ build Backend Rust ไม่สำเร็จ `python start.py` จะข้าม Rust แล้วรันแผนที่ด้วย backend Python ต่อ จึงเรียนคอร์สต่อได้ระหว่างที่ยังแก้เรื่อง Rust ไม่เสร็จ

## อยากอ่านโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.rs` | จุดเริ่มของโปรแกรม กำหนดว่า URL ไหนเรียกโค้ดส่วนไหน |
| `src/routes/` | โค้ดที่รับคำขอจากหน้าเว็บแล้วตอบกลับ |
| `src/services/storage_service.rs` | โค้ดที่อ่านและเขียนไฟล์ข้อมูล |
| `Cargo.toml` | รายชื่อไลบรารีที่โปรเจกต์ใช้ เทียบได้กับ `requirements.txt` ของ Python |

backend นี้ให้บริการ API ชุดเดียวกับ backend Python ดูรายการได้ที่หัวข้อ REST API ใน [README หลัก](../README.md)
